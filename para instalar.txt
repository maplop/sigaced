Ah, esto confirma que better-sqlite3 sigue sin estar compilado para la versión de Node que usa tu Electron. Con Electron v35.7.5, el NODE_MODULE_VERSION es 133, mientras que el módulo fue compilado con la versión 115.

Vamos a solucionarlo paso a paso de manera limpia:

1. Borrar módulos y lockfile
node_modules
pnpm-lock.yaml 

2. Reinstalar dependencias
pnpm install

3. Instalar electron-rebuild
pnpm add -D electron-rebuild

4. Recompilar better-sqlite3 para Electron
npx electron-rebuild -f -w better-sqlite3
Esto generará better_sqlite3.node compatible con Node de Electron.

5. Ejecutar tu app
pnpm dev
